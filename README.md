# رادار امواج (RadioSense)
اپ اندروید فارسی برای سنجش واقعی وای‌فای، بلوتوث، دکل‌های سلولی، ماهواره‌های GNSS و میدان مغناطیسی.

## ساخت APK با گیت‌هاب
1. همه فایل‌ها را در یک ریپو push کنید (شاخه main).
2. تب Actions > Build APK > خروجی `RadioSense-APK` را دانلود کنید.
3. APK را نصب کنید و همه مجوزها + Location را روشن کنید.

## تب رادیو (FM / AM / NFM با RTL-SDR)
1. دانگل RTL-SDR را با کابل OTG به گوشی وصل کنید و آنتن بزنید.
2. اپ «RTL-SDR driver» (marto.rtl_tcp_andro) را نصب کنید و Start بزنید.
3. در تب «رادیو» دکمه «اتصال» را بزنید؛ سپس «جستجوی خودکار» یا تنظیم دستی.

## ظاهر
رابط به سبک شیشه‌ای (glass): کارت‌های نیمه‌شفاف گرد، پس‌زمینه تیره‌ی محو، اعداد درشت باریک، دکمه‌های قرصی و نمودار طیف به شکل میله‌های موج. منطق اپ تغییر نکرده است.

## آیکون
آیکون تطبیقی (adaptive) رادار با پس‌زمینه گرادیان آبی‌سبز؛ نسخه تک‌رنگ برای Themed Icons اندروید ۱۳+ هم دارد.
